# Changelog

All notable changes to SkillWeave will be documented in this file.

## [1.0.0] - 2026-10-23

### Added
- Initial open-source release of SkillWeave.
- Task-first Skill Registry with multi-facet filtering and quick search.
- 3-Dimension Trust Protocol (Provenance, Quality Rubric, Security Permissions).
- Visual Workflow Composer with real-time conflict detection engine.
- Multi-Agent Export Generator for Claude Desktop, Cursor, Windsurf, OpenHands, and CLI.
- PRD Section 17 Worked Example Simulation (Cartoon Character Web App).
- Security Incident Portal, Runtime Feedback Logger, and JSON Import/Export.
