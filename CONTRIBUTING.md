# Contributing to SkillWeave

Thank you for your interest in contributing to SkillWeave!

## Development Guidelines
1. All pull requests must pass TypeScript typechecking (`npm run typecheck`) and Vitest unit tests (`npm run test`).
2. Ensure new skill components include complete 3-dimension trust metadata (provenance commit SHA, quality rubric, tool permissions).
3. Do not introduce mandatory third-party API dependencies for core discovery and composition capabilities.

## Code of Conduct
Please follow our [Code of Conduct](CODE_OF_CONDUCT.md) in all community interactions.
