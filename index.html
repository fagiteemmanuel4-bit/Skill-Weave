Designed for informed reuse

Popularity is a signal. Not a promise.

SkillWeave surfaces repository metadata and a transparent public-signal score. That score is not a user rating, security certification, or guarantee that a skill works. Check the license, read the instructions, and review commands before granting access to your tools.

Search public repositories →Read about skills ↗
Honest status: the current library uses live GitHub repository search and inspects public repository files on demand. A complete, pre-indexed 10,000+ skill catalogue requires a separate scheduled indexing service; live search alone does not guarantee that coverage.

SkillWeave is an independent project and is not affiliated with GitHub, Vercel, or Skills.sh.
